* Notes on the totals

The Rust / Markdown sub-row in tokei's output (947 lines tagged
=Markdown=) is doc-comments inside =.rs= files — tokei pulls them
out so the "Code" total reflects pure Rust.  Same trick for the
Markdown file row, which is why "Markdown · Code = 0".

The "Lines" column = code + comments + blanks; it's what =wc -l=
would report.  "Code" alone is what most people mean by LOC.
