** Tests vs production

Counting raw lines (=wc -l=, includes blanks + comments) so the
arithmetic stays trivial.  Test code lives in three different places
in Rust, all of which the build system gates behind =cfg(test)=:

1. *Integration tests* — every file under =crates/*/tests/=,
   compiled as separate test binaries.
2. *Inline =mod tests {}= blocks* — bodies inside production =.rs=
   files, run alongside =cargo test=.
3. *Sibling test files* — like =top_down/tests.rs=, declared in the
   parent =mod.rs= as =#[cfg(test)] mod tests;= so the file only
   compiles in test mode.  Conceptually identical to option 2 but
   sized to deserve its own file.

Plus =testkit/= — shared test infrastructure (process harness,
assertions), only depended on as a dev-dependency.

A few observations:

- =tip-core-typst= is the test-heavy crate.  The 1741-line
  =top_down/tests.rs= is the biggest single test artifact; its
  fragment-extraction soak suite covers nested towers, hidden bases,
  font-size tracking, the synth-vs-top-down agreement sweep, etc.
  Plus a 2332-line integration suite covering scope skeletons,
  imports, fonts, baseline measurement, and visual checks.
- =tip-core-latex= has zero integration tests today.  Its 343 inline
  lines exercise the project graph and the preview-snippet emitter;
  multi-file integration (tarball-style fixtures) is a known gap.
- =tip-server= has only one integration test (=e2e_tests.rs=,
  219 lines) — the actual server round-trip.  Per-backend handlers
  carry their own inline tests.
- =tip-protocol= is *56% test* (270/(270+477)) — small surface, but
  every wire-shape needs a serde round-trip test, and they live
  inline next to each =struct=.

* Notes on the totals

The Rust / Markdown sub-row in tokei's output (947 lines tagged
=Markdown=) is doc-comments inside =.rs= files — tokei pulls them
out so the "Code" total reflects pure Rust.  Same trick for the
Markdown file row, which is why "Markdown · Code = 0".

The "Lines" column = code + comments + blanks; it's what =wc -l=
would report.  "Code" alone is what most people mean by LOC.
